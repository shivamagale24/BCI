# NeuroCare BCI - React Clinical Staff Dashboard

## Overview
A modern hospital operations dashboard built with React 18 and Vite. Features a clinical dark glassmorphism design, real-time multi-channel EEG waveform canvas, interactive BCI inference execution, and dynamic triage alert dispatch.

## Features
* **Authentication**: Quick login with demo presets for Doctor, Nurse, and Admin roles.
* **Executive Dashboard**: KPI metrics, hospital bed occupancy, and live alert feeds.
* **BCI Monitoring Console**: Multi-channel EEG stream visualizer (10-20 montage) with sensorimotor rhythm (ERD) effects, real-time prediction triggers, confidence breakdown, and intent translation.
* **Inpatients Directory**: Admission form, patient search, and ward status tags.
* **Patient Medical Chart**: Full clinical history, bed assignment, appointments, invoices, and dedicated BCI telemetry audit log.
* **Beds & ICU Allocation**: Ward-level occupancy grid, quick bed assignment, and release/discharge workflows.
* **Clinical Alert Center**: Triage priority queues with audio-visual notifications, one-click acknowledgment and resolution.
* **Appointments & Billing**: Scheduling clinic consultations and managing invoices.

## How to Run Frontend
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.
